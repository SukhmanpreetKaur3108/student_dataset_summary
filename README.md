# student_dataset_summary

## Overview
This project is a Python and Pandas-based analysis of a CSV dataset. The notebook explores the basic structure, characteristics, and quality of the dataset.

## Analysis Performed
The notebook includes:
1. Loading a CSV dataset into a Pandas DataFrame
2. Viewing the first and last few rows
3. Displaying random samples
4. Checking the number of rows and columns
5. Viewing column names and dataset index
6. Checking data types
7. Using `info()` and `describe()`
8. Identifying missing values
9. Calculating missing-value percentages
10. Finding unique values
11. Checking duplicate records
12. Identifying numerical and categorical columns
13. Summarizing basic observations about the dataset

## Technologies Used
* Python
* Pandas
* NumPy
* Google Colab

## How to Run
1. Open the notebook in Google Colab.
2. Run the code.
3. Upload the CSV dataset provided in the LMS Study Material.
4. The program will automatically load and analyze the dataset.
5. Review the generated output and observations.

## Learning Outcomes
After completing this assignment, I learned how to load and explore datasets using Pandas, inspect DataFrame structure and data types, generate descriptive statistics, identify missing and duplicate values, and summarize the basic characteristics of a dataset.
